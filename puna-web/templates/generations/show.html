Open a room from this seed

One generation can back any number of rooms — they are independent multiworlds sharing the same seed, and a second one costs no storage.

Shown on the room, tracker, and feed pages, as well as any other page related to the room. The name can be changed later without restarting the room.

Passwords

Anyone holding the address can connect as any slot. The ordinary choice for a game among people who know each other.

One password for the whole room for every player. Shown to participants and staff on the room page.

Each slot gets its own password, so a player can only connect with their own.

Patch downloads

Anyone with the room URL can download any patch. The patch carries only the room's address, so a player with a password types it into their client themselves.

Only the slot owner can see their patch. The patch carries the address and the slot's credential, where the room has one, so the client it launches connects without being told anything. The credential travels inside the file — which is already a per-slot file served only to that slot's owner and the room's staff.

Feed

Anyone who can open the feed can read the entire history, including chat, connects, disconnects, admin actions, room starts and stops, and hints, and can also download the raw file.

Item movements and Link events only. Organizers always read everything.

The feed is staff-only; anybody else gets nothing.

Tracker

The link is the authorization, just as Archipelago's own tracker works. Shareable with an audience who will never sign in.

A Discord sign-in and a slot or a staff role in this room are required to view the tracker. The race default.

Nobody but staff can see the tracker.

Remote admin

Only for the room server's !admin login. This website's own console drives the room over an authenticated API and needs none of this, so leave it off unless somebody intends to administer the room from inside an AP client.
