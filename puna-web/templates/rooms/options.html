These are decisions this site makes when it answers a request, so they take effect on the next page load — including for people already looking at one. Nobody is disconnected and the room is not restarted.

Tracker

The link is the authorization, just as Archipelago's own tracker works. Shareable with an audience who will never sign in.

A Discord sign-in and a slot or a staff role in this room are required to view the tracker. Links you have already shared will stop working for anyone outside the room.

Nobody but staff can see the tracker. Links you have already shared stop working, and the feed goes with it — it is reachable only where the tracker is.

Feed

Anyone who can open the feed reads the whole history — chat, hints, admin actions, joins and parts — and can download the raw file. This applies to everything already written, not only to what happens next.

The feed shows what happened in the games: item movements, Link events, and goals. Chat, hints and everything else stays with the organizers, who can always see it all and download the raw file.

The feed is staff-only. Anyone holding a feed link gets the same answer as somebody holding a made-up one.

Patch downloads

Anyone with the room URL can download any patch, as archipelago.gg does. The patch carries only the room's address, so a player with a password types it in themselves. Patches already downloaded still carry whatever they were built with — this changes what is served from now on.

Only the slot's owner and this room's staff can download it. The patch carries the address and the slot's credential, so the client it launches connects without being told anything.

Primary room port

The room page leads with the full feed port. The right choice for all but the largest syncs. The filtered port stays available behind a collapsed heading.

The room page leads with the filtered port, which leaves out item traffic the connected slot is not a party to. Large syncs usually want this: many games cannot cope with the bursts a 500-slot+ room produces. Players who already connected on the other port stay where they are unless they switch. Patches carry whichever port leads the room at download time. This changes only what the page recommends, not what each port does.

Passwords

Anyone holding the address can connect as any slot. Turning passwords off opens the room to everybody who has ever been given its address.

One password for the whole room, shown to participants and staff on the room page. Switching to this generates a new one; the old one, if there was one, stops working.

Each slot gets its own password, so a player can only connect with their own. Switching to this generates one per slot, and every player has to be given theirs.
